# Forma OS 2.0

Рабочая среда в браузере: виртуальные диски, файловый менеджер, приложения и управление окнами. Интерфейс сочетает стекло и спокойную палитру Forma с расположением оконных кнопок справа.

## Запуск

Зависимости и сборка не нужны:

```sh
python -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Используйте HTTP на localhost или HTTPS на хостинге. Не открывайте `index.html` через `file://`: доступность хранения и API зависит от браузера.

Для Vercel файл `vercel.json` в корне задаёт `outputDirectory: dist`, без build/install. Root Directory проекта — корень репозитория. На другом статическом хостинге публикуйте содержимое `dist`.

## Файлы и диски

- IndexedDB хранит бинарные файлы, метаданные и вложенную структуру папок.
- Начальные диски: `Forma HD` и `Данные`. Можно создавать и переименовывать дополнительные виртуальные диски.
- Создание папок и текстовых файлов, импорт нескольких файлов, drag-and-drop, поиск в текущей папке, сортировка, сетка и список.
- Копирование, перемещение между дисками, переименование, скачивание, свойства, корзина и восстановление.
- Ctrl/Cmd + C/X/V, Delete, Enter; множественный выбор через Ctrl/Cmd + клик.
- Двойной клик открывает папку или файл. Контекстное меню и кнопка «Действия» доступны для выбранных объектов.
- Ограничение импорта 2 МБ снято: доступный объём зависит от квоты браузера. Все виртуальные диски используют общую квоту сайта.
- Файлы версии 1 автоматически копируются из localStorage в IndexedDB при первом запуске. Старые записи остаются в localStorage как исходная копия; новые операции используют IndexedDB.
- Изменения фиксируются транзакциями. Web Locks, если доступны, сериализуют операции между вкладками; BroadcastChannel обновляет представление в других вкладках.

## Приложения

- Текстовый редактор: UTF-8, ручное сохранение, Ctrl/Cmd + S, «Сохранить как», предупреждение о несохранённых изменениях. Лимит редактирования — 8 МБ.
- Просмотр: изображения, аудио, видео и PDF, если формат поддерживается браузером. Остальные файлы можно скачивать.
- Браузер: вкладки, адресная строка, история введённых адресов, закладки и внешнее открытие. Сайты загружаются в sandboxed iframe; сайты, запрещающие встраивание, нужно открывать снаружи. Внутренние переходы чужого сайта не синхронизируются с адресной строкой Forma.
- Диспетчер: открытые и свёрнутые приложения, время работы и завершение приложений. Он управляет только окнами Forma. CPU/RAM по приложениям не выдумываются; при наличии API показывается только оценка JS-кучи всей страницы.
- Терминал: `help`, `ls`, `disks`, `cd`, `pwd`, `mkdir`, `touch`, `cat`, `write`, `cp`, `mv`, `rm`, `open`, `apps`, `ps`, `kill`, `df`, `echo`, `date`, `whoami`, `clear`. Пути с пробелами заключайте в кавычки. Команды работают с виртуальной файловой системой, не с ОС компьютера.
- Заметки, календарь, калькулятор, локальный аудиоплеер, фокус-таймер и быстрые записи.

## Настройки

Тема, обои, имя, размер текста, уменьшение анимации, показ виджетов, режим концентрации, восстановление списка приложений после перезагрузки. Экран паузы скрывает рабочий стол, но не является парольной защитой.

Раздел «Диски и память» показывает оценку использования и квоты браузера, позволяет запросить постоянное хранение, очистить выбранный виртуальный диск или удалить пустой пользовательский диск. Очистка диска необратима и требует подтверждения. Системный диск удалить нельзя.

## Резервные копии и данные

Настройки → Резервная копия: экспорт и восстановление дисков, файлов, заметок, календаря, быстрых записей, настроек и закладок. Копия версии 2 — JSON с бинарными файлами в base64. Перед заменой данных структура проверяется; восстановление требует подтверждения. Экспорт ограничен 100 МБ исходных файлов, импорт JSON — 150 МБ. Крупные файлы скачивайте отдельно.

Данные локальны для текущего origin и профиля браузера. GitHub, Vercel и Sites не синхронизируют пользовательские файлы. При переходе с одного домена на другой используйте экспорт/импорт. Очистка данных сайта удаляет хранилище. Восстановление сеанса сохраняет список приложений, но не несохранённый текст и не содержимое вкладок браузера.

## Ограничения

Это веб-среда, не нативная ОС и не эмулятор CPU. Нет запуска EXE/APK/macOS-приложений, доступа к системным процессам или управления физическими разделами. Системные настройки компьютера не изменяются. Доступ к выбранным локальным файлам осуществляется только через импорт и скачивание.

## Структура

- `dist/index.html`, `style.css` — рабочий стол и базовое оформление.
- `dist/app.js` — оконный менеджер и исходные приложения.
- `dist/fs-model.js` — правила файловой системы, независимые от DOM.
- `dist/fs-storage.js` — IndexedDB, миграция и транзакции.
- `dist/system.js`, `system.css` — файловый менеджер, браузер, диспетчер, редактор и системные настройки.
- `tests/fs-model.test.cjs` — проверки операций с дисками и файлами.

## Проверка

Нужен Node.js 22+:

```sh
node --test tests/fs-model.test.cjs
node --check dist/app.js
node --check dist/fs-model.js
node --check dist/fs-storage.js
node --check dist/system.js
```

Автоматически проверены правила файловой системы, синтаксис JS и локальные ссылки на ресурсы. Интеграционная проверка IndexedDB и визуальные сценарии в настоящем браузере пока не выполнены.
