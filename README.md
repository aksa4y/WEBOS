# Forma OS

Веб-десктоп в стилистике macOS: окна, Dock, файлы, заметки, календарь, калькулятор, музыкальный плеер, виртуальный терминал и настройки.

## Запуск

Проект не требует сборки или зависимостей. Из корня репозитория:

```sh
python -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Для размещения на хостинге укажите `dist` как корневую папку сайта.

## Возможности

- Перемещение, сворачивание, разворачивание и изменение размеров окон.
- Импорт файлов до 2 МБ, редактирование текста, скачивание, переименование и корзина.
- Заметки и события календаря с локальным сохранением.
- Калькулятор, аудиоплеер для локальных файлов, фокус-таймер.
- Поиск приложений: Ctrl / Cmd + K.
- Тёмная тема, обои и экспорт / восстановление резервной копии.

## Ограничения

Это браузерная рабочая среда, не нативная операционная система. Терминал работает с виртуальными файлами. Сайты открываются в новых вкладках. Данные хранятся в localStorage текущего браузера, без облачной синхронизации; очистка данных сайта удаляет их. Регулярно экспортируйте резервную копию через Настройки.

## Структура

- `dist/index.html` — рабочий стол и виджеты.
- `dist/style.css` — оформление и адаптивная вёрстка.
- `dist/app.js` — приложения, управление окнами и локальное хранение.

## Проверка

```sh
node --check dist/app.js
```

Синтаксис JavaScript проверен. Полная проверка интерфейса в браузере ещё не выполнена.
